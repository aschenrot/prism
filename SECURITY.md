# Security

Prism is a local-first development preview. The current server binds to loopback; do not expose it directly to the public internet. Remote collaboration and authentication are not yet supported production capabilities.

Report suspected vulnerabilities privately using GitHub private vulnerability reporting when enabled, or contact the repository maintainer through a private channel. Do not include live credentials, personal project files or exploit details in public issues. Include affected revision, environment, minimal reproduction with disposable data and impact.

There is no stable release support schedule or guaranteed response time yet. Dependency audits and isolated automated tests are part of verification; they are not a comprehensive security guarantee.
