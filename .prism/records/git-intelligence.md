Expose commits, diffs and historical snapshots, link source references to revisions, compare changes and identify potentially stale documents. Use read-only Git commands with explicit argument handling; no checkout/reset or automatic pushes. Git remains authoritative for history.

Prioritize task-linked commit evidence and reconciliation as a dogfooding requirement before broad repository visualization.
